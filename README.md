# OVOSKG Clothings

A premium multi page React commerce and bespoke tailoring experience for OVOSKG Clothings.

## Stack

React, Vite, Tailwind CSS, Framer Motion, React Router and Lucide icons.

## Routes

- /
- /collections
- /shop
- /lookbook
- /bespoke
- /measurements
- /track
- /about
- /company
- /contact

## Conversion architecture

The build is structured around three primary customer intents:

1. Start a bespoke commission
2. Explore style direction before deciding
3. Track an existing order

The site also includes a persistent mobile conversion bar, WhatsApp contact, style shortlist, bespoke brief builder, virtual measurement profile, FAQ and fitting request flow.

## Remote fitting UX

The site now explains the remote fitting process before a client commits:

1. measurements are reviewed before cutting,
2. inconsistencies can trigger a remeasure, photo check or short video check,
3. approved measurements become the production reference,
4. post delivery fit issues are assessed against the approved measurements,
5. alteration guidance, return correction or remake assessment is then confirmed according to the order terms.

Exact alteration and remake terms should remain part of the quote/order agreement before payment.
