# OVOSKG Clothings Ecommerce Preview

Premium front-end MVP for OVOSKG Clothings.

Included:
- Supplied OVOSKG logo
- Premium responsive homepage
- Men and women bespoke suit categories
- Luxury men's kaftan category
- Bespoke order form with WhatsApp handoff
- Virtual measurement profile UI
- Instructional measurement video slot
- Website order tracker UI with demo order `OVS-DEMO-001`
- Story and journey sections
- Company strategy section
- Editable leadership/HOD data structure
- Client and staff testimonial slots
- Large photography gallery
- WhatsApp, Instagram and TikTok links
- BN 3795532 and business phone
- Paypoint checkout integration slot

## Before production launch

1. Replace editorial preview photography with real OVOSKG photography.
2. Connect a database for customers, orders, measurement profiles, products and staff.
3. Add OVOSKG's Paypoint merchant/API credentials server-side.
4. Replace placeholder testimonials with approved real testimonials.
5. Add the founder's measurement instruction video URL.
6. Confirm the TikTok handle if it differs from `@ovoskg_clothings`.
7. Add the physical boutique address and working hours.
8. Add live ecommerce catalogue, stock, prices, delivery rules and policies.

The UI intentionally avoids inventing prices, customer reviews, staff names or payment credentials.
