# OVOSKG Clothings

Premium React + Vite + Tailwind ecommerce / bespoke tailoring experience for OVOSKG Clothings.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide icons
- React Router
- Custom CSS for editorial details and brand texture

## Current experience

- Responsive multi-route application
- Premium editorial hero and motion system
- Men's bespoke suits
- Women's bespoke suits
- Luxury men's kaftans
- Interactive shop filtering
- Style shortlist persisted in localStorage
- Multi-step bespoke commission builder
- WhatsApp handoff with structured brief
- Virtual measurement profile
- Founder instructional video slot
- Website order tracking UI
- Company strategy and editable department structure
- Founder journey
- Lookbook/gallery layout
- Instagram, TikTok and WhatsApp links
- Custom favicon and web manifest
- Organization / clothing store schema
- Vercel SPA rewrites
- Mobile navigation and floating support controls
