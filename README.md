# OVOSKG Clothings

A premium multi page React commerce and bespoke tailoring experience for OVOSKG Clothings.

## Stack

React, Vite, Tailwind CSS, Framer Motion, React Router and Lucide icons.

## Routes

- /
- /collections
- /shop
- /lookbook
- /bespoke
- /measurements
- /track
- /about
- /company
- /contact

## Conversion architecture

The build is structured around three primary customer intents:

1. Start a bespoke commission
2. Explore style direction before deciding
3. Track an existing order

The site also includes a persistent mobile conversion bar, WhatsApp contact, style shortlist, bespoke brief builder, virtual measurement profile, FAQ and fitting request flow.
